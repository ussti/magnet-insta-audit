# Instagram Analytics Guide Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Пересобрать статический гайд из 11 старых разборов в 15 доказательных аналитических сценариев по своему блогу, аудитории, конкурентам, стратегии и экспериментам.

**Architecture:** Сохранить одностраничную структуру и существующую дизайн-систему `index.html`. Добавить отдельную автоматическую проверку контентного контракта, затем заменить подготовку, проектную инструкцию, промпт-ноль и весь каталог без изменения механики навигации и копирования.

**Tech Stack:** Статический HTML/CSS/JavaScript, Node.js для структурных проверок, локальный HTTP-сервер и браузер для визуальной проверки.

**Spec:** `docs/superpowers/specs/2026-09-01-instagram-analytics-guide-design.md`

## Global Constraints

- Каталог содержит ровно 15 карточек `.qc` с уникальными `data-id`.
- Нет требований к транскрипциям Reels, содержимому первого кадра, монтажу, звуку или тексту слайдов каруселей.
- Промпты конкурентов используют только публичные показатели и не запрашивают их охват, сохранения, репосты или подписки с публикации.
- Наблюдаемая связь не называется причиной.
- Сохраняются текущие классы, навигация, кнопки копирования, чекбоксы и визуальная система.
